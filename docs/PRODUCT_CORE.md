# Relapaw Product Core

## 核心命题：Observation ≠ Interpretation

Relapaw 必须分别保存“发生了什么”和“主人认为这意味着什么”。Observation 是可描述、可追溯来源的客观观察；OwnerInterpretation 是主人的理解。二者在数据库、API 和未来推理上下文中始终为独立对象，不通过一个模糊字段混合。

系统不替宠物说话，不把推测写成事实，不输出“爱主人指数”或“焦虑 92%”一类伪精确结论。未来分析必须表达证据边界、不确定性和可验证的下一步观察。

## Pet Model

保存宠物身份、长期画像、日常行为基线、健康与行为历史。历史用于理解“相对这只宠物平时是否发生变化”，但不能覆盖当前健康风险。

## Owner Model

只描述主人养宠方式、互动方式、观察偏好、回应偏好和解释偏好。它不对主人进行心理诊断，不包含人格障碍、依恋障碍或类似标签。

## Relationship Model

描述人宠以及多宠家庭中宠物之间的长期互动关系和变化模式。关系信息来自可追溯事件与重复观察，而不是一次输入的情绪化定性。Pet↔Pet 可记录共同休息、互动、回避、冲突与资源共享等观察，但不得由单次事件直接生成“嫉妒”“不合”等长期标签。Phase 0.1 仅保留边界，Pet↔Pet 关系建模重点安排在 Phase 6。

## Veterinary Knowledge

未来知识层可包含基础兽医知识、兽医行为学、动物行为学和安全红旗。知识必须可溯源、可版本化，并与个体历史分离。Phase 0 不包含真实医学规则或自动判断。

## Longitudinal Memory

Episode 是进入长期记忆的事件单位，可关联 Observation、OwnerInterpretation、LifeEvent、ObservationPlan 与 VeterinaryEscalation。记忆保留时间、上下文与来源，支持未来复评；任何历史模式都不能降低当前医疗安全优先级。

AI 生成内容不能直接成为长期事实。系统必须区分原始输入、客观观察、主人解释、模型推测和用户确认结果。进入长期记忆的推测必须保留生成来源、证据引用、模型版本和确认状态。

## Evidence and Baseline

重要判断必须能够追溯到具体 Observation、PetBaseline、历史 Episode 或版本化专业知识。证据引用与自然语言结论分离保存，不能只在回答文本中临时描述来源。

Baseline 表达“这只宠物自身平时是什么样”，不是物种平均值。Phase 3 将在原始观察之上增加时间窗口、历史均值或中位数、正常范围、样本量、更新时间和趋势；样本不足时必须明确显示数据不足，不能输出伪精确范围。

## Medical Safety > Behavior Interpretation

当医疗安全与行为解释发生冲突时，医疗安全优先。系统不诊断疾病，不确诊动物心理疾病，不开具处方或用药方案。未来安全层只负责提供合适的升级建议与事实摘要，并且不得被历史画像绕过。

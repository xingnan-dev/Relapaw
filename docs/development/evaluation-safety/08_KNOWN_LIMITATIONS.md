# Known Limitations

1. 真实评估只有两个去标识化案例，不具备统计代表性。
2. 词法禁用内容与语言检查只能发现明确模式，不能证明医学或语义正确。
3. 当前 Adapter 没有向评估器暴露实际 token usage，因此不声明精确 token 消耗或金额。
4. 原始真实输出不进入 Git；仓库仅保留聚合指标、问题类型和人工决定，以降低敏感数据与噪声风险。
5. 自动硬门禁无法可靠发现时间顺序偏移、Observation 复述或隐含因果，需要人工 Review。
6. `NOT_QUALIFIED` 只适用于报告中明确的 Provider、模型、Prompt 和契约组合；更换任何组成部分必须重新评估。
7. 产品中的用户确认是必要安全边界，但不能把未获资格模型转化为自动可靠模型。
8. 本阶段没有完成生产监控、漂移检测、成本遥测、部署或恢复演练。

# Visual Direction Variants

## 目的

基于用户提供的 17 张 UI 参考图，提炼可迁移的字体、字号、排版、组件、颜色与描边规则，并用同一套 Relapaw Today 内容制作四个可直接比较的视觉方向。参考图只作为设计语言来源，不复制具体界面、品牌、文案或构图。

本地预览：启动前端后访问 `http://localhost:5173/visual-variants`。

## 参考图共同语言

### 字体与字号

- 主体均以圆润几何无衬线为主，标题字重约 700–850，正文约 400–550。
- 移动端核心标题常见 32–48px；页面标题与正文形成约 2.2–3 倍比例差。
- 辅助标签多为 11–13px，通过大写、字距或灰度降低优先级。
- 衬线、斜体与手写体只适合作为少量情绪点缀，不能承载 Safety、Evidence 或数据定义。

### 排版

- 高留白、大标题、模块化卡片是共同骨架。
- 首屏通常只强调一个主要动作或一个核心数据，其他信息退为卡片或胶囊。
- 通过错位、叠卡和不规则色块建立编辑感，但功能区内部仍保持严格网格。
- 适合 Relapaw 的密度不是参考图中最紧凑的健康 Dashboard，而是“一主卡 + 两辅助卡”的层级。

### 组件

- 主要动作：实心胶囊或圆角矩形，文字与背景保持高对比。
- 卡片：16–28px 圆角；同屏最多两种圆角尺度。
- 导航：底部浮岛结构清晰，但不得为了造型改变 DOM 和焦点顺序。
- 状态：彩色功能块可用于分类；Safety/Warning/Danger 必须保留独立文字和稳定语义色。

### 颜色与描边

- 内容底色以奶油白或纯白为主，选择 1–2 个主色和 2–3 个粉彩辅助色。
- 参考图中的荧光绿、纯蓝和高饱和紫不适合大面积进入 Relapaw，可降饱和后局部使用。
- 推荐两条描边路线：`1px` 极浅暖灰描边，或 `1.5px` 黑色线稿；避免中灰粗边叠加强阴影。
- 状态色与装饰色必须分离，不能用同一粉红同时表示品牌装饰和危险状态。

## 四个方向

### 01 柔和绘本卡片（推荐主方向）

- 字体：圆润黑体；页面标题 34–44px，卡片标题 24–32px，正文 15–17px。
- 颜色：`#FFF8EE`、`#E9D8F2`、`#CDE8DE`、`#F0B8A7`、`#403746`。
- 组件：1px 暖灰描边、低阴影、奶油白背景、手绘宠物图形。
- 适用：全局壳、Today、Onboarding、Us。
- 风险：若所有卡片都使用粉彩，会降低状态辨识度；需要保留白卡和高对比正文。

### 02 编辑拼贴（局部使用）

- 字体：超大粗标题 36–48px；标签 11–12px；正文 14–16px。
- 颜色：`#FFF4D8`、`#F5D65B`、`#EE9FC2`、`#A8BE78`、`#171719`。
- 组件：黑色实心按钮、1.5–2px 黑边、错位叠卡、强对比色块。
- 适用：每日开场、Today 主行动、比赛演示入口。
- 风险：不适合长表单和 Safety 页面；黑边过多会让产品从治愈感转向潮玩感。

### 03 轻玻璃梦雾（限制使用）

- 字体：中粗标题 24–32px；正文 14–16px。
- 颜色：`#F8F6FF`、`#DED5F4`、`#CFE9E5`、`#F2D6DE`、`#51465E`。
- 组件：乳白半透明卡、无可见硬描边、低饱和渐变、轻微模糊。
- 适用：Understand、Baseline、长期记忆的概览背景。
- 风险：必须压低光效；禁止霓虹、发光球、3D 物体和 AI 科技感。正文卡片仍需不透明底保证对比度。

### 04 线稿粉彩（推荐作为信息层）

- 字体：粗黑标题 32–44px；正文 15–17px；数字可使用更高字重。
- 颜色：`#FFFEFB`、`#F3CADB`、`#D8E6C9`、`#D9D6F3`、`#161619`。
- 组件：1.5px 黑色描边、粉彩状态块、极轻或零阴影、线稿插画。
- 适用：Timeline、Episode Detail、Evidence、状态卡、数据表述。
- 风险：应避免所有容器都描黑边；只给交互边界和关键信息分区使用。

## 推荐组合

以 01 作为全局品牌底盘，吸收 04 的清晰描边和信息层级；在每日开场与 Today 主行动局部使用 02 的编辑感；03 仅用于 Understanding 和长期记忆页面的低强度背景。

```text
全局壳 / Onboarding / Us = 01
Today 主行动 / 比赛展示 = 01 + 少量 02
Timeline / Evidence / Safety = 01 + 04
Understand / Baseline / Memory = 01 + 低强度 03 + 04 状态边界
```

当前对比页是隔离的设计研究入口，不改变生产页面和业务状态机。用户选定方向后，才把对应 token 与组件规则迁移到正式页面。
# 前置流程视觉方向（2026-10-16）

针对 Onboarding 三条原则与首次宠物建档，新增隔离对比入口 `/onboarding-variants`，不替换正式页面、不触发业务 API。

参考图仅用于提炼以下设计规则：中心角色与环绕标签、弧形导航关系、强标题与边缘角色、安静角色叙事。没有复制参考图中的运动习惯内容、角色造型、具体构图或配色。

四个品牌化方向：

1. **漂浮陪伴轨道**：雾蓝与鼠尾草色的探索式空间；
2. **伙伴编辑海报**：高反差标题和边缘探出角色；
3. **安静关系绘本**：低重心插画与连续陪伴故事；
4. **相识手账拼贴**：错层纸页、胶带、贴签，并预告分步资料卡。

当前建议以 04 为产品主方向，吸收 03 的叙事节奏与 01 的少量漂浮标签；02 只用于比赛展示封面。等待人工选择后再迁移至正式 `Onboarding` 与 `PetSetup`。

# Relapaw 产品体验 Beta 人工验收脚本

## 前置条件

- 使用隔离的 Beta 测试账户与非生产数据。
- 后端迁移为当前单一 head；前后端从 `E:\Relapaw-ProductExperienceBeta` 启动。
- 验收真实邮件时只在浏览器输入验证码；不在终端或聊天中输入。
- AI 默认保持关闭；只有具备单次明确授权时才可按已登记资格记录临时启用，完成后立即恢复关闭。

## 桌面与移动核心旅程

1. 新邮箱注册：接收随机验证码，完成三页引导和必要同意；从帮助重新打开引导。
2. 建立宠物：填写少量客观资料，上传、替换、删除 JPG/PNG/WebP 头像；验证跳过时显示默认头像。
3. 简单记录：只写原话即可保存；再验证可选事实、主人理解、安全确认和更多字段不会要求重复输入。
4. 观察计划：无计划时显示独立记录和新建入口；有计划时显示名称、目标和日期范围。
5. 足迹详情：按原话、事实、理解、继续观察、媒体、来源与修改历史阅读；技术内容默认折叠；返回后保留筛选。
6. 媒体：分别在普通记录、生活事件和关系事件上传图片/视频，填写拍摄时间与主人说明，预览、下载并删除；在长期变化中跨时间选择两项比较。
7. “我们”：检查宠物档案、长期变化、关系与家庭三层；编辑/删除照护背景；建立多次互动记录后确认候选门槛、反例、修订、撤回和长期变化纳入。
8. AI 关闭：确认没有生成按钮，但记录、复评、搜索、媒体、记忆、关系、导出和备份均可完成。
9. 安全阻断：建立含当前危险信号的记录，确认页面直接建议联系兽医，候选理解和七段式辅助都不调用模型。
10. 数据生命周期：导出账户，确认新增资料、修订、媒体元数据与已有 AI 运行均存在。归档并恢复唯一宠物，确认数据保留。另在测试副本删除记录及账户，确认到期清理移除相应派生数据与物理媒体。

## 移动浏览器复验

1. 在 320、360、375、390、400、414、430 CSS 像素宽度下依次打开登录、三页引导、建档、今天、记录、补充事实、足迹和我们页面，确认没有横向滚动、逐字断行、控件重叠或底部导航遮挡。
2. 以手机横屏、约 500–640 CSS 像素的小高度和 768px 平板宽度复验；弹层应在视口内滚动，关闭按钮始终可见，Esc 关闭后焦点回到触发按钮。
3. 建档时先验证图片成功；再模拟上传失败，确认基础档案已存在、输入未丢失、可单独重试图片或先进入首页。
4. 聚焦长表单靠近底部的字段并调出真实软键盘，确认字段和保存操作可滚动到可见位置。该项必须分别在 iOS Safari、Android Chrome 和目标 WebView 真机执行，桌面 DevTools 模拟不算通过。
5. 在刘海和底部手势设备检查状态栏、顶部栏、底部导航与弹层安全区。若未来原生容器同时注入安全区，需确认没有双重留白。

## 真实 AI 资格与运行验收

- 使用合成、去标识输入覆盖中文/英文、长文本、提示注入、空知识、撤回知识、错误引用、危险信号、超时、限流、拒绝和无效 JSON。
- 同时验证 facts `text-understanding/v7-verbatim-fact-extraction` 与 guidance `assistant-guidance/v4-versioned-claim-citations`；任何一个契约未通过都不得把模型标为 `QUALIFIED`。
- 人工逐项核对事实/理解分离、记录 ID 血缘、知识引用、不确定表达、无诊断/治疗/剂量、无惩罚式建议以及当前危险优先。
- 最小真实 smoke test 只能在用户明确授权后执行；固定使用合成输入、零重试和隔离数据库，仅记录契约版本、状态、错误代码与聚合计数，不记录密钥、原始供应商响应或私人输入。2026-10-26 的一次性授权已完成 facts v7 与 guidance v4 各一次，均成功；该授权已耗尽，AI 已恢复关闭。

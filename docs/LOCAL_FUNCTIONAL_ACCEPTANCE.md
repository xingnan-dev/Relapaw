# RelaPaw 本地功能验收

验收日期 2026-11-07。基线为 `product-experience-beta` 的 `c8c417862a57e18c8cf636938c593f43dcdbfa11`，结果覆盖本轮工作区修复。入口清单对照 [README](../README.md)、[Beta 验收矩阵](PRODUCT_EXPERIENCE_BETA_ACCEPTANCE.md)、[使用手册](PRODUCT_EXPERIENCE_BETA_GUIDE.md)、[路由注册](../backend/app/api/router.py) 和实际浏览器页面。API 路径以下省略 `/api/v1` 前缀。

使用全新 Python 3.14 虚拟环境、Node 24 锁文件依赖、Chromium、迁移后的空 SQLite 和独立媒体目录。浏览器用例覆盖桌面 1440×1000 及移动模拟视口，包含 360px 输入和多个窄屏、横屏尺寸。邮件用本地固定码或假投递，AI 在浏览器关闭。真实 Resend、模型服务及真机结果另计。

前轮完整回归为后端 261 项、前端 119 项、浏览器 2/2 通过，包含空库迁移、固定合成演示和停机备份恢复后浏览器逐字节核对。本轮保留这些修复，新增到期复评与关系页面补测，复评/关系/媒体/隐私后端专项 **22 项通过**，前端全量 **120 项通过**、TypeScript 与生产构建通过。最终 Playwright **6/6 通过（3.1 分钟）**，覆盖桌面、移动各三条旅程，包含上一轮完整旅程。本轮未重复执行后端全量，261 项按前轮证据记录。

## 文档与范围冲突

| 冲突 | 当前行为和影响 | 需要决定 |
|---|---|---|
| 冻结首发契约要求最小记录至少有一条 Observation，Beta 矩阵允许只写原话。 | 浏览器和 API 都能保存空结构化事实。只写原话的条目不自动补出事实，对以结构化事实为样本的基线有影响。 | 本地验收沿用 Beta 的渐进式记录。若课程或首发要求强制事实，先统一产品契约和验收用例，再同时修改表单和 API。 |
| 冻结契约要求人工 Safety Check，记录页预选正常结果。 | API 仍要求合法的 Safety Check，浏览器可保存默认正常选择。 | 确认“看见默认选项即提交”是否足够，或每条记录都要主动确认。 |
| 旧指南/人工清单写“删除宠物”，当前 UI 与 API 提供可逆归档。 | 已把手册步骤对齐为归档/恢复。归档保留历史与媒体，和账户到期清理的语义不同。 | 若学生项目要提供单宠永久删除，先定义复评、关系、基线、媒体和备份的处理范围。 |
| 旧 README 的 Qwen v5 未获资格和无 RAG 口径，与后续 Beta 资格和受控资料引用描述混用。 | v5 旧组合和登记的 v7/v4 组合是两套证据。当前本地交付按 AI 关闭验收，知识引用只在已批准的受控资料范围内。 | 启用生成能力要单独确定范围并验证指定契约。 |
| 旧演示手册写“无需账号”，Beta 默认强制会话。 | 已把 Beta 演示统一为固定合成账号和测试码，保留鉴权。冻结比赛目录另行保存。 | Beta 的本地入口按更新后的 README 使用。 |

## 待决定的本地交付范围

以下按当前 Beta 行为验收。删除回执、批量导出、最简记录、Safety 默认值和单宠退出规则标为 **待决定**，本轮沿用现状。AI 关闭已属于本地交付范围，表末澄清历史版本口径。

| 事项 | 用户实际看到什么 | 当前缺少什么 | 需要确认的范围 |
|---|---|---|---|

## 剩余缺陷与补测

1. **待决定。** 删除回执与完成通知、个人媒体打包、最简记录/复评事实必填、Safety 默认值及单宠永久删除，逐项见上表。当前已验收行为继续适用，范围决定后再改产品规则。
2. **待补测（浏览器）。** 手工长期记忆引用/移除具体媒体、人工及量化基线的各窗口与来源失效；观察计划编辑/取消；生活事件编辑；生活和关系来源各自的视频上传/元数据修订。这些有现存 API/组件或共用媒体组件证据，独立浏览器覆盖尚不完整。到期完成/取消复评、关系多日候选全生命周期及双项图片比较已在本轮完成。
3. **已知本地工具边界。** 备份工具使用与应用源码相邻的默认布局，README 给出临时数据操作方法。旧版遗漏头像的备份缺少头像字节，需从仍有原文件的源副本重新备份。
4. **后续环境补测。** iOS Safari、Android Chrome 真机的相册/相机格式、软键盘、安全区和目标 WebView 仍缺直接证据。当前交付范围是本地运行与浏览器视口，真机和真实投递/真实模型调用按后续选定范围验收。
